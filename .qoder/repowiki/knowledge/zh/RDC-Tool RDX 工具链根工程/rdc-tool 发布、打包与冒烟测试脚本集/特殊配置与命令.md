常用工作流见 `scripts/README.md`：先运行 `python -B scripts/check_markdown_health.py`、`python -B scripts/generate_tool_reference.py --check`，再 `python scripts/package_release.py` 产出 zip，最后 `python scripts/release_gate.py --require-smoke-reports --require-release-package` 作为 CI gate；冒烟测试需通过 `bash scripts/smoke_cli.sh` 或带 `--rdc <path>` 的 daemon 模式，日志落 `intermediate/logs/smoke_cli.log`；Windows 安装器使用 `python scripts/rdx_tool_install.ps1 -Action install -AddToPath`，建议先用 `-DryRun` 验证。
