脚本按职责划分为四类，统一通过 `_shared.py` 暴露 `tools_root`、`run_subprocess`、`write_text`、`load_json`、`extract_json_payload` 等工具函数：
- 构建与打包：`package_release.py` 基于 `RELEASE_DIRS`/`RELEASE_ROOT_FILES` 白名单扫描仓库根目录生成 staging 树，输出 `RELEASE_MANIFEST.json`、`LICENSE_INVENTORY.json`、`SBOM.json`，压缩为 `rdc-tool-<version>-windows-x64.zip` 并附带 `SHA256SUMS`；`generate_release_checksums.py`、`verify_release_package.py`、`package_runtime.py` 配合完成校验。
- 发布门禁：`release_gate.py` 是核心编排器，依次检查目录/文件结构、运行时 manifest 完整性、捆绑 Python 布局、用户文档约束（禁止 pip/venv/uv 引导、禁止在用户文档中使用 `rdx.bat` 命令示例）、catalog 公开面一致性、MCP 未暴露、`tool-reference.md` 新鲜度、公共入口 `rdc --help/--json doctor/version/tools list/context status/list/update/clear/vfs ls` 等正向用例以及若干负向用例（期望特定错误码），并将结果汇总写入 `intermediate/logs/release_gate_report.md`。
- 冒烟测试：`smoke_cli.sh` 通过 bash 直接调用 `bin/rdc-tool`，记录每一步到 `intermediate/logs/smoke_cli.log`，可选加载 `.rdc` 捕获走 daemon 链路，并在结束时写 `tool_smoke_findings.md`；`preview_geometry_smoke.py` 校验预览窗口几何。
- Windows 安装：`rdx_tool_install.ps1` 支持 install/upgrade/uninstall/doctor 四种 action，将源码复制到 `LOCALAPPDATA\Programs\rdc-tool`，可选择加入用户 PATH 并执行 `rdc.bat --json doctor` 自检。
依赖方向单向：各脚本 → `_shared.py` → 仓库顶层 `rdc_tool` 包（如 `rdc_tool.runtime_paths`、`rdc_tool.python_runtime`、`rdc_tool.runtime_catalog`）；脚本之间仅 `release_gate.py` 显式 import `scripts.package_release` 复用排除规则。
