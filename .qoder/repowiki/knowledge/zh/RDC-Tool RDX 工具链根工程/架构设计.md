根级 pyproject.toml 使用 `package-dir = {"": "."}` 配合 `include = ["rdc_tool*"]` 把各子模块统一纳入一个 Python 包；`[project.scripts]` 将 `rdc-tool` 入口指向 `rdc_tool.cli:main`，由 CLI 经 JSON-first 的 `rd.*` 操作协议调用 rdx_runtime 的守护进程+工作进程架构，后者再调度 CoreEngine 异步处理器完成渲染捕获、回放、预览等任务。spec_catalog 从运行时注册表生成公开的 tool_catalog.json，被 CLI 的 `tools list/describe` 消费，形成“定义→目录→命令”的单向契约。platform_binaries 提供 Windows x64 与 Android 平台的 RenderDoc 可执行与 Vulkan/OpenGL 捕获层，由 scripts_and_packaging 的构建/发布脚本打包成自包含 zip，并由 tests 中的 smoke/集成用例验证 CLI、守护进程、重放、VFS、预览及 fixture 一致性。pytest 配置集中在根级 `[tool.pytest.ini_options]`，通过 markers（unit/contract/fixture_integration/gpu_live）区分测试类型，所有子模块共享同一份测试约定。
