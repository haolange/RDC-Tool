该模块为纯资源型产物目录，按目标平台/架构隔离：`windows/x64/` 放置渲染捕获核心 `renderdoc.dll`、Vulkan Loader/Layer 描述文件 `renderdoc.json`（声明全局层 `VK_LAYER_RENDERDOC_Capture`、库路径、API version 1.4.324、启用的 instance/device extensions 以及环境变量开关）、调试辅助 DLL（`dbghelp.dll`、`symsrv.dll`、`d3dcompiler_47.dll`），以及内嵌的 Python 3.14 嵌入式发行版——`python/` 含完整标准库、`DLLs/` 下的 C 扩展 `.pyd`（如 `_ssl.pyd`、`sqlite3.dll`、`tcl86t.dll`、`tk86t.dll`、`vcruntime140*.dll`），并通过 `pymodules/renderdoc.pyd` 暴露 RenderDoc 的 Python 绑定；`android/arm32` 与 `android/arm64` 分别存放对应 ABI 的 `org.renderdoc.renderdoccmd.*.apk`。各平台子树之间无相互依赖，仅由上层构建系统按目标平台选取对应目录发布。所有文件通过根级 `manifest.runtime.json` 以相对 path + size + sha256 三元组记录，用于构建期完整性校验与不可变分发。
