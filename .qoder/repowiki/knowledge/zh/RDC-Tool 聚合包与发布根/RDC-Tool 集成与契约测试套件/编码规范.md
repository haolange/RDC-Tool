- 每个测试文件通过 `from rdc_tool import ...` 或 `from rdc_tool.<submodule>` 直接导入被测模块内部函数，并以 `test_` 前缀命名用例。
- 对外部副作用（网络、文件系统、子进程、全局状态）统一通过 `monkeypatch.setattr` / `monkeypatch.setenv` 进行打桩，而非修改被测代码。
- 需要持久化状态的测试在 `tmp_path` 构造临时目录后，再 `monkeypatch` 相关路径访问器（如 `daemon_worker.binaries_root`）指向该临时目录。
- 对 JSON 输入/输出的测试同时覆盖合法 payload、BOM 编码、非法 JSON、非对象类型等多种边界情况，并使用 `pytest.raises(..., match=...)` 断言错误消息片段。
- 涉及文档与静态资源的测试通过读取 `docs/` 与 `tests/fixtures/` 中的文件，断言内容与自动生成产物或哈希一致，防止文档与代码定义漂移。
