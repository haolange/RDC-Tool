模块由三个文件构成单向流水线：build_catalog.py 通过 `sys.path.insert(0, ROOT)` 将仓库根加入导入路径后动态导入 `rdc_tool.runtime_catalog.catalog_payload`，序列化并写入 spec/tool_catalog.json；tool_catalog.json 作为单一事实源，包含 schema_version、source_path、fingerprint、tool_count、groups 以及每个 rd.* 工具的 name/group/description/parameter_raw/returns_raw/input_schema/prerequisites/scope/effects/evidence_kind/path_inputs 等元数据；validate_catalog.py 作为独立 CLI 读取该 JSON，按顺序执行基础计数与唯一性、名称前缀 rd.、已废弃别名清理、可读性（防 mojibake 与占位符）、schema 约束（prerequisites.requires 白名单、when 白名单、via_tools 非空且禁止自引用、supports_projection.tabular 需声明 projection 参数），并以递增退出码区分错误类型。依赖方向严格为 build → JSON 产物 ← validate，二者互不反向依赖。
