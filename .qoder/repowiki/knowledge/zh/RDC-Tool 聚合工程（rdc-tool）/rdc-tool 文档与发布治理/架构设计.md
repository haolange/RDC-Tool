本模块为纯 Markdown 文档集合，无代码或构建产物；`README.md` 作为导航入口，按功能域组织链接到各专题文档：使用指南（quickstart、install）、运行时模型（session-model、agent-model、agent-integration、rdc-tool-native-agent-playbook）、工具体系（tools、tool-reference、tool-interface-upgrade、fixture-strategy）、运维与质量（configuration、troubleshooting、public-contract、stability）、发布流程（release-notes、release-baseline）以及治理规范（doc-governance）。`doc-governance.md` 明确规定文档与代码的边界：操作定义唯一来源为 `rdx/operation_definitions.py`，`spec/tool_catalog.json` 与 `docs/tool-reference.md` 为生成输出，禁止二次覆盖；变更需通过 `python -B spec/build_catalog.py` 与 `python -B scripts/generate_tool_reference.py --check` 验证一致性。预览几何相关变更需同步更新 `preview_geometry_smoke.py` 与用户文档，确保测试与文档一致。
