- 跨进程/跨上下文的错误通过 `core.contracts.canonical_error` 包装为统一的 `{code, category, message, details, trace_id, transport}` 信封返回。
- 守护进程与客户端共享的超时参数通过 `_normalize_timeout` 或显式 `_normalize_context` 做容错归一，避免非法值破坏 JSON 状态。
- 长生命周期服务（CoreEngine、ServerRuntime、SessionManager 等）采用模块级单例 + 惰性初始化模式，避免重复创建底层资源。
- 需要并发安全的状态更新统一用 `threading.Lock` 保护字典写入，并通过 `save_daemon_state`/`save_context_state` 原子落盘。
- 操作分发先记录 start、再执行业务逻辑、最后记录 finish，并将 `process_identity` 注入 payload.meta 作为统一审计字段。
