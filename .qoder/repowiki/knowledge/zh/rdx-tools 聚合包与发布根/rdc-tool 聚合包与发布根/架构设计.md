根目录作为聚合层，不承载业务逻辑，而是把以下子模块拼装成可发布的 rdx-tools：
- rdc_tool/ 提供 CLI、守护进程、核心引擎、handlers、utils 等运行时代码；binaries/ 内嵌 Windows x64 的 RenderDoc 捕获层、Python 3.14 与 SPIRV-Tools，Android arm32/arm64 APK。
- scripts/ 中的 package_release.py、release_gate.py、generate_release_checksums.py 等脚本在构建时从 spec/tool_catalog.json 与 runtime_identity 推导制品元数据，并把 binaries/ 下的平台产物打包进最终 zip。
- spec/ 维护 tool_catalog.json 的 schema 与校验，cli/run_cli.py 通过 spec.build_catalog 动态发现工具命令，实现“代码注册 + JSON 目录”的双契约。
- tests/ 覆盖 CLI、守护进程、运行时、重放、安装、发布门禁等跨子模块边界；docs/ 提供用户与开发者指南；.github/workflows/ci.yml 驱动 CI 对构建、测试与发布门禁进行统一编排。
- intermediate/ 是构建与测试过程中的临时工件输出目录（artifacts、logs、pytest、runtime），被 .gitignore 忽略。
