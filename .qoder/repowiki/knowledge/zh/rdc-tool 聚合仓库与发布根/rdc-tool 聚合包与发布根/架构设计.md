本仓库按职责分层组织子模块：
- `rdc_tool/` 提供 Python 宿主包（CLI、守护进程调度、原生运行时代理生命周期）；`bin/rdc-tool.cmd` 与 `cli/run_cli.py` 是其对外可执行入口。
- `binaries/` 预分发 Windows x64 与 Android arm32/arm64 平台二进制（Vulkan 捕获层、内嵌 Python 3.14、APK），由 `scripts/package_runtime.py` 与 `package_release.py` 组装进最终制品。
- `spec/tool_catalog.json` 由 `spec/build_catalog.py` 从运行时注册表生成，并由 `spec/validate_catalog.py` 校验，作为公开契约被 CLI 消费。
- `tests/` 覆盖 Python 层行为；`intermediate/native-replay/` 存放基于真实设备交互的 JSON 快照式契约测试数据，与 `pytest` 套件共同保障工具契约稳定。
- `docs/` 集中用户与开发者指南，`scripts/release_gate.py`、`check_markdown_health.py` 等脚本在 CI (`github/workflows/ci.yml`) 中串联构建、打包、冒烟与文档检查。
子模块之间通过约定目录结构、JSON 契约文件与脚本接口协作，而非共享运行时库。
