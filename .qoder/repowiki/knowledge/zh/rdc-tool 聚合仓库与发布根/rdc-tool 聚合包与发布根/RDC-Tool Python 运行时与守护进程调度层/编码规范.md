- 异步操作统一返回标准信封 `{ok, data, artifacts, error, meta}`，错误经由 `core.contracts.canonical_error` 规范化后再上抛。
- 长耗时任务通过 `ProgressEvent`（含 trace_id、operation、stage、progress_pct、ts_ms）经 stdout JSON 行上报，由 `RuntimeWorkerProcess._pump_stdout` 单向泵出。
- 跨进程状态（daemon_state.json、session_state.json、worker_state.json、context_state.json）一律通过 `io_utils.atomic_write_json` 写入，并以文件锁 + 内存 `threading.Lock` 双重防竞态。
- 领域处理器遵循 `<domain>/<handler>.py` 单文件结构，每个模块暴露一个带 `@register_operation` 装饰器的 `handle` 协程，并在 `tool_router._DOMAIN_HANDLERS` 中以域名字符串映射。
- 路径解析集中在 `runtime_paths.py`，所有 I/O 通过 `binaries_root()` / `pymodules_dir()` 获取，避免硬编码绝对路径。
- 对外暴露的异常类继承自 `CoreError` / `RuntimeToolError`，并通过 `map_exception` 在 server_runtime 层统一转换为 envelope.error。
