本模块由三个文件组成单向流水线：build_catalog.py 通过导入根包 rdx.runtime_catalog.catalog_payload 动态收集已注册的工具定义，序列化为 JSON 并写入 spec/tool_catalog.json；tool_catalog.json 是单一事实源，包含 schema_version、source_path、fingerprint、tool_count、分组统计 groups 以及每个 rd.* 工具的 name/group/description/parameter_raw/returns_raw/input_schema/prerequisites/scope/effects/evidence_kind/path_inputs 等元数据；validate_catalog.py 作为独立 CLI 读取该 JSON，执行多层校验——基础计数与唯一性、名称前缀 rd.、已废弃别名清理、可读性（防 mojibake 与占位符）、schema 约束（prerequisites.requires 白名单、when 白名单、via_tools 必须非空且不能自引用、supports_projection.tabular 需声明 projection 参数），并以不同退出码区分错误类型。依赖方向严格为 build → JSON 产物 ← validate，二者均不反向依赖彼此。
