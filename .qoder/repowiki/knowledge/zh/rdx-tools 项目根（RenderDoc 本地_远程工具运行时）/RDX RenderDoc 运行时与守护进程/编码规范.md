- 所有公开操作以 rd.<domain>.<action> 三段式命名注册到 OperationRegistry，handler 统一实现为 async def handle(action, args, env) 并在 tool_router._DOMAIN_HANDLERS 中集中映射。
- 操作参数在进入 handler 前由 runtime_catalog.validate_operation_arguments 依据 input_schema（支持 type/enum/oneOf/not/required/properties/items 等）进行校验，失败返回结构化 validation_error。
- 异常处理采用 try/except 捕获后调用 core.errors.map_exception 转为标准错误对象，再通过 contracts.canonical_error 输出包含 code/category/message/details/trace_id 的统一错误结构。
- 成功响应通过 contracts.canonical_success 包装，并经由 ArtifactPublisher.publish_candidates 自动收集 data 树中的 artifact 候选项，使返回值格式标准化为包含 schema_version、tool_version、result_kind、ok、data、artifacts、meta 的结构。
- 跨进程/跨上下文的状态通过 context_snapshot、runtime_state、daemon/client.save_daemon_state 以 JSON 文件持久化，文件名按 context 安全化（仅保留字母数字及 -_.）区分 default 与自定义 context。
- 长生命周期资源（RenderDoc 回放线程、GPU 上下文）在 runtime_worker.py 中以单线程 ThreadPoolExecutor(max_workers=1) 复用，避免每次请求创建销毁导致原生句柄失效。
