顶层 pyproject.toml 将 `rdx` 脚本入口指向 `rdx.cli:main`，并通过 `package-dir = {"": "."}` 与 `include = ["rdx*"]` 把多个子模块（rdx_runtime、platform_binaries、scripts_and_packaging、spec_catalog、tests、docs）统一纳入一个 Python 包；CLI 通过 JSON-first `rd.*` 操作协议调用 runtime 的守护进程+子进程架构，后者再调度 CoreEngine 异步处理器完成渲染捕获、回放、预览等任务。spec_catalog 从运行时 catalog 生成公开的 tool_catalog.json，被 CLI 的 `tools list/describe` 消费，形成“定义→目录→命令”的单向契约。platform_binaries 提供 Windows x64 与 Android 平台的 RenderDoc 可执行与 Vulkan/OpenGL 捕获层，由 scripts_and_packaging 的构建/发布脚本打包成自包含 zip，并由 tests 中的 smoke/集成用例验证 CLI、守护进程、重放、VFS、预览及 fixture 一致性。
