该模块为纯资源型产物目录，按目标平台组织：`windows/x64/` 包含渲染捕获核心 `renderdoc.dll`、Vulkan 层描述文件 `renderdoc.json`（声明 `VK_LAYER_RENDERDOC_Capture` 全局层及其扩展与入口）、调试辅助 DLL（`dbghelp.dll`、`symsrv.dll`、`d3dcompiler_47.dll`）以及内嵌的 Python 3.14 运行时（`python/` 含标准库、`DLLs/` 下的 C 扩展 `.pyd`、`vcruntime140*.dll`），并通过 `pymodules/renderdoc.pyd` 暴露 RenderDoc 的 Python 绑定；`android/arm32` 与 `android/arm64` 分别存放对应架构的 `org.renderdoc.renderdoccmd.*.apk`。`manifest.runtime.json` 以 JSON 清单形式记录所有文件的相对路径、大小与 SHA-256 校验值，用于构建期完整性校验与分发打包。各平台产物之间无相互依赖，仅由上层构建系统按目标平台选取对应子树进行发布。
