- 所有公开能力通过 JSON-first 的 `rd.*` 操作定义并在 CLI 中以 `rdx tools list/describe` 暴露，新增功能需同步更新 spec_catalog 生成的 tool_catalog.json。
- CLI 输出统一支持 `--json` 格式以便机器消费，Windows 启动器额外支持 `--non-interactive` 标志。
- 会话状态通过 `rdx context status/update` 维护，多上下文通过 `--daemon-context <id>` 隔离，避免并发冲突。
- 测试按 pytest markers 分类：unit、contract、fixture_integration、gpu_live，分别对应无需样本、契约校验、外部样本与真实 GPU 环境三类用例。
