- 所有脚本通过 `tools_root(__file__)` 解析仓库根，并以 `RDX_TOOLS_ROOT` 环境变量覆盖默认位置，保证跨环境一致。
- 对外部命令的统一封装：Python 侧使用 `_shared.run_subprocess`，bash 侧使用 `run_raw` 包装 `timeout`，均捕获 stdout/stderr 并返回退出码。
- 发布产物采用白名单过滤：仅允许 `RELEASE_DIRS` 与 `RELEASE_ROOT_FILES` 下的文件进入 staging，并通过 `EXCLUDE_DIRS`/`EXCLUDE_FILE_SUFFIXES` 剔除缓存与二进制工件。
- 发布门禁以 `results.append(("category:name", ok, detail))` 形式收集单项检查结果，最终汇总为 Markdown 报告并输出整体 PASS/FAIL。
- 用户文档约束通过正则集合（如 `USER_PATH_FORBIDDEN_RULES`、`MCP_DOC_MARKERS`）在 `release_gate.py` 中集中声明并逐文件扫描，避免硬编码分散判断。
- 需要外部依赖（如 `rg`）的检查优先尝试外部命令，失败时自动回退到纯 Python 实现以保证在无 ripgrep 环境下仍可运行。
